# Configuração do cálculo do diferencial de alíquota (DIFAL)

Agora é possível alterar a configuração padrão e aplicar um cálculo específico para cada estado. Em "Preferências de Venda" no grupo "Emissão de NF-e" selecione "Configuração do Cálculo DIFAL". A nova tela para configuração por estado será exibida.

![](https://http2.mlstatic.com/storage/developers-site-cms-admin/DevSite/340603782323-configuracaododifal-png)

Cada estado possui duas opções de cálculo para serem selecionadas. São elas: "Padrão" e "Específico do estado".

- O modo de cálculo "Padrão" segue as instruções da nota técnica 2015.003;   
- O modo de cálculo "Específico do estado" segue a legislação que cada estado criou para o cálculo do DIFAL.

Para mais informações e detalhes sobre o DIFAL veja o nosso FAQ através da [Configuração DIFAL](https://www.mercadolivre.com.br/ajuda/Configura%C3%A7%C3%A3o-DIFAL_4963).
