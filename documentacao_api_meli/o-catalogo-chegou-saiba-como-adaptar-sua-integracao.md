# O que é catálogo

Nota:

Este recurso está disponível para Argentina, México, Brasil, Colômbia, Chile, Uruguai, Peru e Equador.

Atualmente, os vendedores podem criar publicações de catálogo com o conteúdo (títulos, fotos, descrições e dados técnicos) fornecido pelo Mercado Livre. As publicações podem ser feitas a partir de publicações atuais ou criando uma publicação, competindo com outros vendedores, tendo as melhores condições de vendas para ganhar exposição na página do produto. Essas páginas estão posicionadas na parte superior dos resultados da busca.

Saiba [mais informações do catálogo](https://vendedores.mercadolivre.com.br/nota/com-o-catalogo-o-primeiro-lugar-dos-resultados-de-busca-pode-ser-seu) e veja mais detalhes no vídeo:
