# Recebendo notificações

Lembre-se que **o desenvolvimento deve estar assinado às notificações de "invoices"**. Conheça mais como [trabalhar com notificações](https://developers.mercadolivre.com.br/pt_br/produto-receba-notificacoes#Inscreva-se-para-receber-notificacoes). Assim, você começará a receber notificações depois de gerada uma venda na plataforma e confirmado o pagamento.

**Seguinte:** [Obtendo nota fiscal](https://developers.mercadolivre.com.br/pt_br/obtendo-nota-fiscal).
