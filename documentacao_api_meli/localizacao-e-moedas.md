# Localização e moedas

Os seguintes exemplos servirão para obter as localizações e moedas disponíveis no Mercado Livre.

Nota:

No recurso de zip\_code, países como Chile, Equador e Perú, Mercado Livre ainda não oferece os códigos locais (CEPs) API, de forma que permite ao vendedor ou integrador criar sua própria lógica de identificação para cada localidade.

Importante:

**Especificamente para o México, deve-se seguir a guia atual para a moeda 'Peso Mexicano', sem alterações na forma de carregar as moedas. Nos fluxos de demanda, será exibido o símbolo MXN, enquanto o dólar (USD) será mantido.**
